# Ojas Patkar — Portfolio

A personal portfolio built with React, TypeScript, TanStack Start, Tailwind CSS, and Vite.

## Development

Install [Bun](https://bun.sh), then run:

```sh
bun install
bun run dev
```

Open http://localhost:3000. Run `bun run build` for a production build and `bun run test` for the test suite. The production Node server is generated at `.output/server/index.mjs`.

## Personalize

Edit `src/data/profile.ts` to update your bio, skills, contact details, and projects. The landing page uses a clean black background with silver typography. Its opening animation transitions from OJAS to PORTFOLIO.

The intro plays on every page load and refresh, supports Escape, and respects reduced-motion preferences.
